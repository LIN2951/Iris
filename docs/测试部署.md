# 测试

Iris 小手机的一键后端搭建测试版。前端是静态网页，部署后直接在手机浏览器打开。

## 从这里开始

小手机 → 全局设置 → 部署。

- **使用公共服务**：勾选音乐、后台通知，点击「连接公共服务」。无需 Cloudflare 账号。
- **自己搭建**：登录 Cloudflare → 选择服务 → 使用默认地址或填写自己的域名 → 点击「搭建并连接」。全过程在网页内完成，不运行命令。

自建服务使用用户自己的 Cloudflare 账户和额度。后台通知需要浏览器支持系统通知。

当前 Iris OAuth 应用仍为 Private，维护者自己的 Cloudflare 账号可以先测试授权。向其他 Cloudflare 账号开放前，需由维护者完成域名验证并设为 Public。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → main → / (root)。

此测试发布副本不包含作者站点的 CNAME，页面保留在自己的 GitHub Pages 地址。安装清单使用相对路径，支持不同仓库名。

## 文件导航

| 位置 | 用途 |
| --- | --- |
| index.html、style.css | 网页入口和样式 |
| scripts/ | 各功能页面和前端逻辑 |
| config/ | 版本、安装清单和服务地址 |
| cloudflare/ | 音乐和通知后端源码 |
| cloudflare/deploy/ | 公共授权与部署服务源码，供维护者管理 |
| assets/ | 字体、图片、地图及素材许可证 |
| docs/ | 功能和维护说明 |
| tests/ | 自动检查 |
| tools/ | 维护者构建工具 |

## 发布副本

发布副本从当前文件生成，不携带原仓库历史、本地密钥、缓存或日志。Cloudflare 客户端 ID 和服务网址是公开配置，不是账号密码。`.dev.vars`、`.env` 及其真实配置不上传。
